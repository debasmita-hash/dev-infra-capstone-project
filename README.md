# DevOps and Cloud Infrastructure Capstone Projects

This repository contains a collection of hands-on DevOps, cloud infrastructure, automation, CI/CD, security, monitoring, containerization, and configuration-management projects.

The projects demonstrate practical experience with AWS, Terraform, GitHub Actions, Docker, Kubernetes, Ansible, Linux, IAM, CloudWatch, Route 53, ACM, S3, EC2, ECR, and Application Load Balancers.
